# Samples of the score

Notes of the General MIDI instruments of **FluidR3_GM** (Frank Wen, free to use and redistribute), as packed by
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts). Only the instruments the score uses, and only a
few notes of each (the engine re-pitches the nearest one). `manifest.json` lists them: `{ instrument: [midi notes] }`,
and each note is `<instrument>/<midi>.mp3`. The names are the engine's (`table3d/music/instruments.ts`).
